## 🚀 Projects

### 📝 [FastAPI Blog](https://github.com/EvanKN9/fastapi-blog)
A full-stack blogging application built around a REST API using **FastAPI and PostgreSQL**.

- User authentication and authorization
- CRUD operations for posts and users
- PostgreSQL database with SQLAlchemy
- Database migrations with Alembic
- Profile image uploads and processing
- Async database operations
- RESTful API design

`FastAPI` `PostgreSQL` `Jinja HTML` 

### 🎬 [Movie Watchlist](https://github.com/EvanKN9/Frame25)

A movie tracking application for organizing movies and building personal watchlists.

Currently evolving the project toward a larger full-stack application with persistent database storage and external movie data.

`Python` `FastAPI` `PostgreSQL`
